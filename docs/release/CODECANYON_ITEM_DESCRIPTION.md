# VendorHub — Multi-Vendor E-Commerce & Delivery Platform

## 🚀 Complete Solution for a Multi-Vendor Marketplace

VendorHub is a production-ready, enterprise-grade multi-vendor e-commerce
platform with video commerce, real-time delivery tracking and offline-first
architecture.

### 🎯 Perfect For:

- ✅ Multi-vendor marketplace startups
- ✅ Food & grocery delivery businesses
- ✅ Any multi-vendor e-commerce platform

---

## 📱 What's Included

### 3 Mobile Applications (Flutter)

1. **Customer App** — browse, order, track deliveries, video commerce, subscriptions
2. **Vendor App** — manage orders, products, inventory, branches, thermal printing
3. **Driver App** — delivery management, GPS tracking, earnings ledger

### Backend System (Laravel 11)

- RESTful API with clean architecture
- JWT multi-guard authentication
- Admin panel & seeded demo data
- Real-time notifications & queue processing

---

## ⭐ Key Features

### 🎬 Video Commerce
- TikTok-style short videos, vertical swipe feed
- Instant product purchase from videos
- Engagement metrics

### 🗺️ Zero-Cost Maps
- OpenStreetMap integration (free)
- Optional Google Maps support
- Hot-swappable map providers
- Real-time GPS tracking

### 🖨️ Thermal Printing
- ESC/POS protocol implementation
- Bluetooth printer support
- Receipt & kitchen-copy printing
- Byte-level formatting

### 📡 Offline-First
- Isar local database
- Automatic sync when online
- Background GPS tracking
- Queue-based updates with retry

### 💰 Multiple Payment Gateways
- Stripe · Paystack · Razorpay · PayPal (configurable) · Cash-on-delivery

### 🏢 Multi-Branch Support
- Geo-fencing, branch inventory, nearest-branch detection, operating hours
